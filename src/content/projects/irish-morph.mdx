This project is a small but fairly opinionated toolkit for Irish (Gaeilge) language processing, combining lexical lookup, phonetic analysis, and structured morphological data handling.

At its core are two complementary Python modules built around data from BuNaMo (Bunachar na Gaeilge Morphology). One module focuses on what words mean and sound like; the other focuses on how words inflect and behave grammatically.

The lookup and analysis module provides Irish–English dictionary functionality backed by multiple sources (Word2word, WordReference, and Wiktionary), with a single aggregation interface for retrieving short definitions and translations. Beyond simple lookup, it includes phonetic and phonological tooling: Irish text can be converted to IPA using Epitran, compared using phonetic matching algorithms such as Beider–Morse and ALINE, and evaluated via weighted phonetic feature similarity. A range of string-based similarity metrics (e.g. Levenshtein, Jaro–Winkler) are also included, allowing direct comparison between orthographic and phonetic similarity.

The morphology module handles structured grammatical data extracted from XML dictionaries. It parses full Irish verb conjugation paradigms—covering tense, mood, person, number, and independent/dependent forms—as well as noun declensions across case, number, and gender. The parsed data is normalized into Pandas DataFrames with multi-level indices built from enum values rather than raw strings, enabling efficient filtering, querying, and even bitwise operations over grammatical categories. Each row represents a concrete inflected form tied back to its headword and grammatical features.

Although the phonetic and morphological components are not directly coupled in code, they are designed to coexist within the same linguistic ecosystem. The phonetic tools can be applied to forms generated by the morphology pipeline for tasks such as pronunciation comparison, phonological alternation analysis, or fuzzy matching of inflected forms. As a whole, the project serves as a foundation for more advanced Irish NLP work—bridging dictionary lookup, phonology, and morphology in a way that keeps the data explicit, queryable, and extensible.


### DataFrame details

#### Verb DataFrame Structure

##### MultiIndex (4 levels)

- **`Headword`** - Base form of the verb (e.g., `"bí"`, `"déan"`)
- **`Disambig`** - Disambiguation identifier (optional, for homonyms)
- **`MoodAndTense`** - Combined mood/tense info (`VerbMoodTense` enum values like `PAST`, `PRES`, `FUT`, `CONDT`, `IMPER`, `SUBJPR`, `PASTH`, `PRESC`, `NONFINITE`)
- **`PersAndNum`** - Person/number/dependency (`VerbDPNG` enum values like `IND_1ST_SG`, `DEP_3RD_PL`, `UNI_AUTO`, `VERBNOUN`, `VERBADJ`)

##### Columns

- **`Form`** - The actual inflected word form

##### Example structure
```
                                                        Form
Headword Disambig MoodAndTense PersAndNum                    
bí       None     PAST         IND_1ST_SG               bhíos
                               DEP_1ST_SG               rabhas
                  PRES         IND_1ST_SG               táim
                  NONFINITE    VERBNOUN                 bheith
```

#### Noun DataFrame Structure

##### MultiIndex (3 levels)
- **`Headword`** - Base form of the noun (e.g., `"fear"`, `"bean"`)
- **`Disambig`** - Disambiguation identifier (optional)
- **`NumAndCase`** - Number and case (`NounNumberCase` enum values like `SgNom`, `SgGen`, `SgDat`, `SgND`, `PlNom`, `PlGen`, `PlND`)

##### Columns

- **`Form`** - The actual inflected word form
- **`FormGender`** - Gender of that specific form (NounGender enum: M, F, or MF)

##### 

```
Example structure
                                            Form          FormGender
Headword Disambig NumAndCase                                 
fear     None     SgNom                     fear           M
                  SgGen                     fir            M
                  PlNom                     fir            M
                  PlGen                     fear           M
```

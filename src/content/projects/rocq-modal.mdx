**Modal.v** formalizes **modal logic** in **Coq**, a proof assistant, to create a rigorous framework for reasoning about necessity, possibility, and their extensions into **deontic (ethical) and temporal (time-based) logic**. This project stands out for its implementation of **obligation (OB), permission (PE), and prohibition (NO)** operators, enabling precise ethical reasoning, as well as **temporal operators (G, H, F, P)** for analyzing time-dependent statements. These additions allow the system to model complex real-world scenarios—such as ethical AI decision-making or time-sensitive system behaviors—with mathematical precision.

A key strength of this work is its support for **inference rules** and **modal collapse**, which simplify nested logical expressions while preserving correctness. For example, the system can derive whether an obligation implies a permission or collapse redundant temporal statements, ensuring efficient and error-free reasoning. By leveraging **Coq’s formal verification**, every rule and simplification is mechanically proven, eliminating ambiguity and guaranteeing reliability. This makes the framework invaluable for applications in **AI ethics, legal reasoning, security protocols, and real-time systems**, where precise logical analysis is critical.

This project demonstrates expertise in **formal methods, theorem proving, and logical system design**, making it highly relevant for roles in **research, AI safety, or systems engineering** where rigorous reasoning and verification are essential.

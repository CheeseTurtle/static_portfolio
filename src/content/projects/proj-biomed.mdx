This project is a real-time biomedical data collection and analysis system built in MATLAB for a university research lab, designed to turn raw experimental signals into immediately usable insight. At its core, the application continuously ingests live data, identifies meaningful structures in that data, and presents the results visually as they happen—allowing researchers to adjust experiments on the fly instead of waiting for post-processing.

Under the hood, I designed a custom object-detection pipeline that evaluates candidate features using weighted scoring and mathematical curve fitting, allowing noisy or ambiguous data to be validated statistically rather than heuristically (weighted detection, regression-based validation). To keep the system responsive under live experimental conditions, I implemented a bespoke queue-driven execution model that supports concurrent processing and event-based coordination across multiple threads (producer–consumer queues, asynchronous event handling, MATLAB parallel execution).

The user interface was built to make advanced analysis approachable. Researchers can configure inputs through an interactive graphical interface, visually crop regions of interest via drag-and-drop controls, and monitor incoming images and plots in real time as data is acquired (GUI programming, interactive ROI selection, real-time rendering). The application also supports seamless export of processed images and numerical results through both menu actions and clipboard integration, enabling rapid transfer into reports, spreadsheets, or publications (CSV generation, image serialization, system clipboard access).

Overall, the project balances mathematical rigor, performance-oriented architecture, and usability—bridging the gap between experimental hardware and human interpretation in a live research setting.
